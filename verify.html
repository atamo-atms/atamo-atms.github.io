Verification Guide

A simple public guide showing how users can independently verify the authenticity of the ATAMO system.

How to verify ATAMO

Users should rely on official public references and independent blockchain verification rather than screenshots, social posts, or copied addresses.

Quick verification checklist

  • Verify you are on the official domain: atamo-atms.org
  • Confirm contract addresses on the contracts page
  • Compare sources with the official GitHub repository
  • Verify release signatures using the PGP verification guide

Release verification

Official ATAMO releases are cryptographically signed using PGP. This allows anyone to verify that the release artifacts were produced by the project maintainers.

View release verification guide
1. Start from the official domain Begin only from atamo-atms.org and avoid links copied from chats, posts, or screenshots.
2. Confirm the official contract references Open the contracts page and compare the published addresses with blockchain explorer records before interacting with any token or platform.
3. Match the release and source references Compare the deployment references with the official GitHub repository, release tag, and public documentation.
4. Verify signed release artifacts when available Use the published PGP key and release verification guide to confirm that release files were signed by the project maintainers.
