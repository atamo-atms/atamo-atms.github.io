Release Verification

Official ATAMO releases are cryptographically signed using PGP. This allows anyone to independently verify that a release was created by the project maintainers.

Public signing key

All official ATAMO releases are signed using the project's public PGP key.

Public key location:

https://atamo-atms.org/.well-known/pgp-key.txt

PGP fingerprint:

05E5 39A2 05D1 33DE 4446 0BD6 3311 09D8 AFF8 B090

GitHub reference:

github.com/atamo-atms/atamo-project

How to verify a release

1. Import the ATAMO public key

Download the public PGP key

curl -O https://atamo-atms.org/.well-known/pgp-key.txt

Import the key into GPG

gpg --import pgp-key.txt

2. Download the release and signature

Download the manifest and its signature

curl -LO https://github.com/atamo-atms/atamo-project/releases/download/v1.0.0/manifest-2026-03-14.txt

curl -LO https://github.com/atamo-atms/atamo-project/releases/download/v1.0.0/manifest-2026-03-14.txt.asc

Download the source archive (optional, for code verification)

curl -LO https://github.com/atamo-atms/atamo-project/releases/download/v1.0.0/atamo-v1.0.0-source.tar.gz

3. Verify the PGP signature of the manifest

gpg --verify manifest-2026-03-14.txt.asc manifest-2026-03-14.txt

You should see something like:

gpg: Good signature from "ATAMO Security "

4. Check file integrity using SHA256 checksums

sha256sum -c manifest-2026-03-14.txt

This will verify all files listed in the manifest match the published checksums.

Always verify releases against the official repository and PGP signature before using them in production environments.
