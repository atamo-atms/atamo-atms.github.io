Get ATAMO

This page defines the official public routes for obtaining ATAMO and the verification rules that must be followed before interacting with any token, pool, exchange, or distribution process.

Official acquisition rule

ATAMO should only be obtained through routes explicitly published on this page and verified against the official token proxy address.

If a token, swap link, exchange listing, sale page, claim page, or distribution route is not published here, it should be treated as untrusted.

Name, symbol, and logo are not proof of authenticity. The contract address must match the official SecureToken proxy.

Verification requirement

Before obtaining ATAMO, verify the token proxy against the official contracts page, public blockchain records, signed release artifacts, and official verification references.

Users, wallets, exchanges, explorers, analytics providers, and integrations should use only the SecureToken proxy address for normal ATMS token interaction.

Implementation contracts are not user-facing token contracts.

2. Mandatory security checks

  • Use only the official ATAMO website and official contract references.
  • Do not trust token addresses copied from chats, social posts, screenshots, ads, or direct messages.
  • Verify the token proxy on the contracts page and a public blockchain explorer before interacting.
  • Verify signed release artifacts if relying on release files or downloaded references.
  • Verify that the acquisition route is explicitly published on this page.
  • Start with a small test transaction before any larger transaction.
  • Confirm the received token contract is 0x38604c42c16e29BbFbc5479668453f18cB6cf335.

3. Official acquisition route status

Only routes explicitly marked active on this page are official acquisition methods.

Centralized exchange route

Any exchange claiming to list ATAMO without being referenced here should be independently verified and treated as untrusted until confirmed.

Direct distribution route

Status: Not active unless an official claim, sale, or treasury distribution route is published on this page.

Any unlisted direct sale, claim page, airdrop page, or treasury offer should be treated as untrusted.

4. Recommended acquisition process

1. Verify the official token contract Confirm the ATAMO SecureToken proxy on the contracts page before using any wallet, swap, exchange, or distribution route.
2. Verify that the route is officially published Use only an acquisition method explicitly listed on this page.
3. Verify the release references when needed If using downloaded release files, verify the signed Git tag, PGP fingerprint, SHA256SUMS.asc, and SHA256SUMS.
4. Perform a small test transaction Use a limited amount first before sending a larger transaction.
5. Re-check the received asset Confirm after acquisition that the received token matches the official ATAMO contract address in your wallet or on a public explorer.

5. Release verification reference

ATAMO v1.0.0 release verification is based on a signed Git tag and a signed SHA256 checksum manifest.

Canonical release tag:

v1.0.0

Release directory:

releases/v1.0.0/

Release verification files:

  • deployment-manifest.mainnet.json
  • deployment-records-full.mainnet.json
  • ATAMO_DEPLOYMENT_STATEMENT_mainnet_2026-05-16.txt
  • SHA256SUMS
  • SHA256SUMS.asc
  • ATAMO_RELEASE_PGP_PUBLIC_KEY.asc

These files support independent verification of release integrity, deployment authenticity, and official contract references.

6. Anti-impersonation rule

Attackers may attempt to impersonate ATAMO through fake swap links, copied token symbols, fake exchange listings, fake token contracts, fake claim pages, manipulated search results, or misleading social posts.

If a route, token, or instruction does not match the official domain, official contracts page, signed release artifacts, and public verification references, it should be treated as malicious or incorrect.
